Parent account setup

Verify your recovery email

First use your welcome email’s one-time setup code to choose a password. Then request a separate email-verification code. Household access stays closed until your current email is verified.

Enter the new email-verification code, not the welcome setup code. Codes are cleared when you leave.

If the intended email changes, verify the current address before activating. A competing action refreshes the pending state; password setup alone does not activate the account.

Invalid or expired code: request another code and try again. If an operation’s result cannot be confirmed, keep its request ID for operator help; do not repeat the mutation.
